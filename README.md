# ایجنت تولید ویدیو (video-producer)

ایجنتی برای Claude Code که از روی بریف، سناریو، استوری‌بورد، فایل نریشن و یک ویدیوی نمونه، ویدیوی موشن‌گرافیک کامل می‌سازد: تصویر، موسیقی، افکت‌ها و نریشن، همه با کد.

## ابزارهای نصب‌شده

| ابزار | مخزن | نقش |
|---|---|---|
| givemotion | github.com/givemotion/givemotion | موتور اصلی: HTML به ویدیو، بررسی خودکار فریم‌ها، تحلیل ویدیوی نمونه، میکس صدا، رندر |
| Remotion | npm `remotion` نسخه‌ی 4.0.242 | موتور جایگزین بر پایه‌ی React. برای شرکت‌های بیش از ۳ نفر لایسنس پولی می‌خواهد |
| Lemo-Opuscar | github.com/lemomo-ai/Lemo-Opuscar | روش کارگردانی، افکت و موسیقی با کد، لیمیتر، کنترل صدای گوینده |
| pdoom-video | github.com/mexicat/pdoom-video | هم‌ترازی کلمه‌به‌کلمه، تحلیل ضرب، موتور three.js |
| PDoomVideo | github.com/JohnHeibel/PDoomVideo | سبک نقاشی‌شده با p5.brush، راهنمای کار موازی چند ایجنت |
| awesome-opus5-5-videos | github.com/yihui-dev/awesome-opus5-5-videos | کتابخانه‌ی ۷۰۳ ویدیوی ساخته‌شده با کد و پرامپت‌هایشان، برای پیشنهاد سبک وقتی ویدیوی نمونه ندارید |
| ابزارهای کمکی | `scripts/` | ساخت پروژه، تحلیل ویدیوی نمونه، زمان‌بندی نریشن، نرمال‌سازی صدا |

## شروع سریع

### سشن ابری (claude.ai/code)

1. یک سشن جدید بسازید و رپوی `bayanenoGroup/video-agent` را انتخاب کنید.
2. لازم نیست چیزی نصب کنید. هوک SessionStart در اولین شروع سشن، همه‌ی ابزارها را در حدود یک دقیقه نصب می‌کند. اگر نصب خطا داد، گزارشش در `~/.video-tools-setup.log` است.
3. ورودی‌ها را در پیام اول پیوست کنید: نریشن (mp3)، ویدیوی نمونه (mp4)، استوری‌بورد، سناریو، لوگو و اسکرین‌شات‌ها.
4. درخواست را بنویسید، مثلاً:

   > با ایجنت video-producer یک پروژه به اسم `my-reel` بساز و فایل‌های پیوست را در input بگذار. سبک ویدیوی نمونه را رعایت کن و موسیقی متن و افکت‌ها را هم بساز. رنگ برند: #FF6A2B. کلمه‌های «رایگان» و «نامحدود» ممنوع است.

   پرامپت سبک (مثلاً پرامپت یک ویدیوی مرجع) را هم می‌توانید در همین پیام بگذارید.
5. ایجنت این کارها را خودش انجام می‌دهد: تحلیل نمونه، زمان‌بندی روی نریشن، ساخت موشن، طراحی صدا و دانلود کتابخانه‌های لازم، بررسی فریم‌ها و رندر. در پایان MP4 را تحویل می‌دهد. اولین ویدیو حدود ۱۰ تا ۲۰ دقیقه طول می‌کشد.
6. سشن ابری بعد از مدتی پاک می‌شود. MP4 را دانلود کنید، یا بخواهید پروژه کامیت شود تا بعداً بتوانید ویرایشش کنید.

### روی سیستم خودتان

پیش‌نیازها: Node 22، Python 3، ffmpeg و Chrome. روی ویندوز از WSL استفاده کنید.

```bash
git clone https://github.com/bayanenoGroup/video-agent
```

```bash
cd video-agent && bash setup.sh
```

```bash
claude
```

بعد همان درخواست قدم ۴ را بنویسید. فایل‌ها را می‌توانید پیوست کنید، یا خودتان در `videos/<name>/input/` بگذارید.

### اگر ویدیوی نمونه ندارید

لازم نیست حتماً نمونه بفرستید. اگر نفرستید، ایجنت سناریو و استوری‌بورد را بررسی می‌کند و در کتابخانه‌ی awesome-opus5-5-videos (۷۰۳ ویدیو) نزدیک‌ترین‌ها را پیدا می‌کند. بعد **کار را متوقف می‌کند** و این را برایتان می‌فرستد:
- ۳ نمونه‌ی پیشنهادی، هر کدام با لینک تماشا و دلیل انتخاب
- نمونه‌ای که خودش توصیه می‌کند
- تغییرهای لازم در استوری‌بورد، به‌صورت جدول «قبل ← بعد» برای هر شات

تا وقتی شما نمونه را انتخاب و تغییرها را تأیید نکنید، ایجنت کار را ادامه نمی‌دهد. استوری‌بورد اصلی شما سر جایش می‌ماند و نسخه‌ی اصلاح‌شده جداگانه ذخیره می‌شود (`storyboard.v2`).

### ویرایش‌های بعدی

کافی است تغییر را بگویید، مثلاً «صحنه‌ی ۶ را کوتاه‌تر کن»، «رنگ را عوض کن» یا «با Remotion بساز». کد ویدیو در `build/` می‌ماند و فقط بخش‌های تغییرکرده دوباره ساخته می‌شوند.

## نصب

**روش خودکار:** پوشه‌ی `video-agent` را در Claude Code باز کنید (`cd video-agent && claude`). هوک SessionStart در اولین اجرا همه‌ی ابزارها را در `~/video-tools` نصب می‌کند. این کار حدود یک دقیقه طول می‌کشد.

**روش دستی:**

```bash
bash video-agent/setup.sh
```

```bash
export VIDEO_TOOLS=~/video-tools PATH=~/video-tools/bin:$PATH
```

**استفاده در پروژه‌ی دیگر:** پوشه‌ی `.claude/` این ایجنت را در آن پروژه کپی کنید و `setup.sh` را یک‌بار اجرا کنید.

## استفاده

**۱. ساخت پروژه:**

```bash
new-video-project 9router-reel
```

**۲. گذاشتن ورودی‌ها:** این فایل‌ها را در پوشه‌ی `videos/9router-reel/input/` بگذارید:
- `brief.md`: پرامپت، هدف، رنگ و فونت برند، ادعاهای ممنوع
- `scenario.md`
- `storyboard.md` یا `storyboard.html` یا یک تصویر
- `narration.mp3`
- `reference.mp4`: ویدیوی نمونه‌ی سبک
- پوشه‌ی `assets/`: لوگو، اسکرین‌شات‌ها و فونت

**۳. صدا زدن ایجنت در Claude Code:**

> با ایجنت video-producer ویدیوی پروژه‌ی videos/9router-reel را بساز.

**مراحلی که ایجنت طی می‌کند:**
1. ورودی‌ها را می‌خواند و سبک ویدیوی نمونه را تحلیل می‌کند: کات‌ها، ریتم، رنگ و تمپو.
2. زمان هر جمله‌ی نریشن را پیدا می‌کند و صحنه‌ها را روی آن می‌چیند.
3. موشن را در givemotion می‌سازد. اگر بخواهید، با Remotion.
4. برنامه‌ی صدا را خودش از روی سناریو و استوری‌بورد می‌نویسد: حس هر بخش، تمپو، گام، سازها و یک افکت برای هر اتفاق تصویری. کتابخانه‌ی سازهای لازم را خودش دانلود می‌کند و موسیقی و افکت‌ها را با Lemo-Opuscar می‌سازد. لازم نیست کاربر نام سازی را بگوید.
5. فریم‌ها را خودش بررسی و اصلاح می‌کند.
6. ویدیو را با 1080p و 60fps رندر می‌کند و صدا را روی ‎-14 LUFS تنظیم می‌کند.
7. MP4 را با گزارش کار تحویل می‌دهد.

## نمونه

پروژه‌ی کامل موشن‌ریل 9Router در `templates/example-9router/` است، شامل `reel.html`، `audio.py` و `timeline.json`. ایجنت از الگوهای همین پروژه استفاده می‌کند.

## محدودیت‌ها

- **صدای گوینده:** ایجنت صدای گوینده نمی‌سازد. فایل نریشن را شما می‌دهید، مثلاً از ElevenLabs.
- **هم‌ترازی کلمه‌به‌کلمه:** هم‌ترازی pdoom-video مدل‌های سنگین Whisper و CTC و ابزار `uv` لازم دارد و اختیاری است. به‌طور پیش‌فرض، زمان جمله‌ها از روی سکوت‌های فایل نریشن پیدا می‌شود.
- **سازهای واقعی:** همراه ایجنت نیستند. ایجنت موقع ساخت هر ویدیو فقط کتابخانه‌ای را که لازم دارد دانلود می‌کند (۷۴ تا ۴۱۵ مگابایت). برای نصب از قبل: `WITH_INSTRUMENTS="karoryfer vcsl" bash setup.sh` یا `WITH_INSTRUMENTS=all` (حدود ۱٫۴ گیگابایت).
- **لایسنس Remotion:** برای پروژه‌های شخصی رایگان است. فقط اگر ویدیویی برای یک شرکت بزرگ‌تر از ۳ نفر ساخته شود، لایسنس شرکتی لازم است.
